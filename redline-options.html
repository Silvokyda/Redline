Design skills

Built-in styles are ready to use. Choose one in Redline before an AI redesign, or install your own prompt profile below.

Custom skill file formats

Import a JSON profile or a self-contained Markdown skill file (including Claude SKILL.md). For Markdown, Redline uses the main file text; linked reference files aren’t imported.

{
  "name": "Quiet luxury",
  "description": "Refined, understated styling",
  "instructions": "Use a restrained palette, clear typography, and..."
}

Skill files contain text instructions only. They are stored locally and sent to your selected AI provider when used.

Your key and installed skills are stored only in this browser (chrome.storage.local). When you request an AI redesign, your selected provider receives the screenshot, page summary, and chosen skill instructions. Quick fixes never leave your browser.
